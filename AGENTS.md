# AGENTS.md

## Project
CardRadar is a web tool for collecting and displaying Pokemon card buylist posts from X/Twitter.

## Current UI direction
- Make the main experience timeline-based.
- Keep the store list simple.
- Store list should mainly show store name and latest update date.
- Do not use thumbnails as the main UI.
- Keep the search/header area compact.
- Show the search bar only when useful, such as while scrolling.
- Keep the hamburger menu idea.
- Do not add X/Twitter account icons for now.
- Design should support future regions beyond Osaka/Nipponbashi.
- Avoid forcing users to select Osaka -> Nipponbashi every time.

## Development rules
- Make small, safe changes.
- Explain files before editing them.
- Preserve existing features unless removal is clearly justified.
- Keep the UI mobile-friendly.
- Use Japanese labels where appropriate.
- After changes, summarize modified files and how to test.
